# Лабораторная работа №1. Изучение средств защиты GNU/Linux

**Операционная система:** РЕД ОС 8.0.3 (Standard Server Minimal)  
**Среда:** Oracle VM VirtualBox

## Выполненные задания

### 1. Создание пользователя
Создан пользователь `user1` с UID 1234, добавлен в группу `students`. Настроена обязательная смена пароля каждые 90 дней.

### 2. Мониторинг файлов и процессов
Выполнен поиск файлов с установленным битом set-UID. Обнаружен процесс `su` с RUID = 1000 и EUID = 0.

### 3. Механизм set-UID
Создана копия утилиты `cat`, принадлежащая root, с правами `4755`. Продемонстрировано чтение защищённого тестового файла без использования sudo.

### 4. Механизм Linux Capabilities
Создана копия утилиты `chown`. Назначена привилегия `CAP_CHOWN`. Успешно изменён владелец тестового файла без sudo.

### 5. Механизм sudo
Пользователю `user1` предоставлено разрешение на изменение системного времени через `/usr/bin/date -s`. Конфигурация проверена командами `visudo -c` и `sudo -l -U user1`.
